## 开始：安装与初验

1. 先确定这台机器负责什么。 用一张连接图说明机器人、上位机和 GPU 服务器之间的数据流。读者按用途选择安装步骤：上位机直接运行录制程序、上位机只运行设备服务、另一台机器运行录制或推理客户端，以及 GPU 服务器只运行 learner 或策略服务。分别标明命令在哪台机器执行，以及哪端需要硬件 SDK。

2. 按设备选择依赖。 分别列出机械臂、夹爪、相机和遥操作的安装项。遥操作部分用一张表回答“我手里有这个设备，要装什么”。

| 遥操作设备或输入方式 | 安装与配置要点 |
|---|---|
| SpaceMouse | 在实际读取 USB 设备的机器安装 spacemouse extra，检查 HID 访问权限。 |
| GELLO | 在连接 Dynamixel 总线的机器安装 gello extra；使用实体键盘或踏板切换、标注时，再安装 gello-events。 |
| Pico VR 控制器 | 安装 pico extra，配置并检查控制器的 ZeroMQ 数据源。 |
| 主从机械臂 | 按主臂硬件安装对应后端，说明如何从设备服务读取主臂，以及关节空间跟随和笛卡尔映射分别适用于什么配置。 |
| 键盘、终端与脚本事件 | 桌面键盘使用 pynput；SSH 会话可从终端读取标注；可重复测试可使用 JSONL 事件。说明这些输入能控制哪些回合事件。 |

3. 在没有硬件时完成安装初验。 检查包导入、`rwrl` 入口和 mock doctor。接入真实设备后的检查放在“搭建工作站与遥操作录制”，读者能明确知道自己已经验证到哪一步。

## 搭建工作站与遥操作录制

| 章节 | 读者要完成的操作 |
|---|---|
| 建立工作站 | 配置 station 和任务 preset，读取 Franka、夹爪和相机状态；看清机械臂安装方式，测桌面坐标系 task_frame（SpaceMouse 读数 → base_R_table → 基座系 → 末端目标 → 控制器）。解释 station 描述“接了什么设备”，preset 描述“这次实验用什么观测和动作”。 |
| 选择并配置 Franka 控制器 | 介绍 impedance、internal、serl 三种控制器；按新机器人的型号、robot server version 和内核选择，在 NUC 上安装对应软件（serl：脚本从源码一起构建 franky + serl_controller，不用 Docker），写 station 字段，用 doctor 和归位验收。安装顺序：用 serl 时不跑 doctor --install-sdk。 |
| 用 SpaceMouse 遥操作 | 读取六轴和按钮，在桌面坐标系里建立方向档案，核对工作区。先用默认 tracker 练习接管、夹爪和交还，再解释 SERL 模式的差异，按 HIL-SERL 摆放 SpaceMouse 并做六个单轴检查。 |
| 用 GELLO 遥操作 | 找到串口和关节 ID，检查关节方向、偏移与夹爪标定；对齐主从姿态后接管、操作和交还。说明所选配置发出的是关节动作还是笛卡尔动作。 |
| 录制与标注示范 | 从 SpaceMouse 或 GELLO 章汇入同一录制流程。完成一个回合，标记成功或失败，观察结束后的保持与下一轮复位。 |
| 检查录制结果 | 打开完整归档，找出人工接管区间、送入环境的动作和实测位姿变化。再检查哪些数据进入了训练用 .pkl，以及失败尝试保存在何处。 |

这一组的终点：读者能用自己选择的设备完成一次录制，并指出归档里哪一段是自己操作的。双臂 GELLO 接管作为扩展案例，单独讲左右映射与独立接管。

## 用示范训练行为克隆（BC）

这一组集中讲如何从真机示范得到一个可检查的 BC checkpoint。

1. 准备训练数据。 从录制章节的产物选取示范，检查观测字段、相机名称、动作维度、动作含义和人工控制标记。用 SpaceMouse 和 GELLO 各举一例，解释为什么同样是“移动夹爪”，记录下来的动作可能有不同含义。
2. 训练第一份 BC 策略。 给出本仓训练入口、最小配置、输入输出目录。讲清模型看到一次观测时，要预测示范中的哪个动作，以及 human_action_mask 怎样参与监督。
3. 离线检查 checkpoint。 用一条保存的观测运行推理，对照预测动作和示范动作。记录模型依赖的相机、状态字段和动作约定，供部署章核对。

这一组的终点：读者得到可加载的 checkpoint，并能解释它的一条输入和一条输出。这份 checkpoint 是部署章的第一个例子。

## 部署与推理

这一章放在真机强化学习之前，提供两个入口。

| 入口 | 教程内容 |
|---|---|
| 部署本仓训练的 BC 策略 | 从 BC 章节的 checkpoint 恢复配置，对照当前工作站的相机、状态和动作约定。先用保存的观测检查输出，再完成一次受监护的部署回合，记录策略动作、实测运动和回合结果。 |
| 部署已有 openpi / RLinf 策略 | 从“拿到一个 π0.5 checkpoint，但不确定能否用于现场”开始。识别权重布局、加载器、归一化统计和训练任务；用官方 pi05_base 讲清 openpi → RLinf 的转换，用 RLinf-Pi05-Pick_Red 核对单臂 Franka 任务配置。随后分别检查 GPU 策略服务、`rwrl deploy-openpi --dry-run` 和工作站动作映射。 |

Pick_Red 已找到上游真机配置。本仓通过 WebSocket 加载该策略并完成推理仍待实际验证，教程实施时会把它作为独立验证项。双臂 Clean Desk 放在扩展阅读，用来解释同为 Franka 时，双臂观测和动作布局还多了哪些要求。

进入真机强化学习前的检查：读者已经验证 actor 所用的观测与动作配置，知道策略如何产生动作，也知道如何停止当前回合、读取执行记录。真机强化学习复用这套工作站和配置；示例会单独说明 HIL-SERL 的策略初始化方式。

## 在真机上做强化学习（HIL-SERL）

1. 先看懂一次在线实验。 用一张图标明机器人设备服务、actor 和 learner 分别运行在哪里。沿一个时间步说明：actor 在哪里取得观测、谁决定实际动作、奖励和下一条观测去了哪里。
2. 准备一个可训练的任务。 配置复位、回合结束、成功判定、奖励来源和示范数据。先验证一次成功标注和一次失败标注能在记录里区分。
3. 启动 HIL-SERL。 按机器给出启动顺序、命令和预期输出。先观察 actor 产生数据、learner 收到样本，再确认参数更新能回到 actor。
4. 做一次人工纠正。 SpaceMouse 与 GELLO 并列给出接管、纠正和交还步骤。两条操作路径汇入同一项检查：找到策略原本提出的动作、实际执行的动作、人工控制标记，以及 learner 收到的对应样本。
5. 评估与恢复。 保存 checkpoint，分别统计任务成功和自主成功；演示训练中断后怎样确认本地数据、恢复 learner，并部署新策略做独立评估。

这一组的终点：读者能追踪一次真实的人工纠正，从操作员接管开始，一直到样本进入 learner，再到新策略回到 actor。BC 的训练过程、模型的部署过程和真机在线学习各有独立章节，也能用同一个实验顺序串起来。
