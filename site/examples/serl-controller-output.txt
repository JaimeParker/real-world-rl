# start doctor-warn
示例：常见的 WARN／FAIL 行（同样是格式示例）。
FAIL           franka.sdk:serl_controller: the installed franky_control 2.0.0 is not the wheel serl_controller was built against (libfranky.so sha256 <a> != <b>; e.g. the official wheel instead of the one from the same build)
WARN           franka.config:serl_control: cartesian_controller: serl ignores control: ['translational_stiffness', 'rotational_stiffness'] (franky Cartesian tracker gains); Cartesian servo runs SERL's controller with the serl: parameters
WARN           franka.mode:serl_realtime: cartesian_controller: serl with realtime: ignore: SERL's 1 kHz torque loop ran with realtime enforced (franka_control); without it, jitter can trip communication reflexes
WARN           franka.mode:robot_model: robot_model: panda but the robot's URDF (Robot.model_urdf) is a fr3; SERL's joint reset would use the panda joint limits
# end doctor-warn
# start recover-log
示例：反射（reflex）停掉 SERL 控制器后，下一个 servo 目标触发自动恢复时的日志（WARNING 级别）。
arm 'franka': SERL impedance controller stopped (<libfranka 的错误文字>); auto-recovery 1/5 this episode: clearing errors and restarting the controller at the measured pose
示例：本回合已经自动恢复 5 次，第 6 次不再自动处理，servo 报可恢复错误：
franka SERL impedance controller stopped: <错误文字> (serl_auto_recover: max_per_episode 5 reached, 5 auto-recoveries this episode)
示例：错误清不掉（例如外部使能按钮仍按下）时：
franka SERL impedance controller stopped: <错误文字>; recover_from_errors failed: <原因> (serl_auto_recover could not clear it)
# end recover-log
